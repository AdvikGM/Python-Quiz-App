# 🧠 Python Quiz App

A simple beginner-friendly Python quiz game built using basic Python concepts.

---

## 🎯 Features
- Multiple-choice questions
- Score tracking system
- Simple terminal-based interface
- Beginner-friendly code (no advanced libraries)
